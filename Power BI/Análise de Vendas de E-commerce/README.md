## :bar_chart: Dashboard de Análise de Vendas — E-commerce

:pushpin: Sobre o projeto

Este projeto consiste no desenvolvimento de um dashboard de análise de dados de vendas de uma empresa de e-commerce, com o objetivo de transformar dados brutos em informações visuais que auxiliem na compreensão do desempenho comercial e na tomada de decisões.

A proposta foi criar uma visão gerencial e intuitiva dos principais indicadores de vendas, permitindo identificar tendências, comparar resultados e acompanhar o comportamento dos pedidos.

:dart: Objetivos
- Analisar a evolução das vendas ao longo do tempo;
- Acompanhar os principais indicadores comerciais;
- Identificar categorias com maior participação na receita;
- Analisar a distribuição dos pedidos por canal de venda;
- Monitorar o status dos pedidos recentes;
- Facilitar a interpretação dos dados por meio de visualizações interativas.
- 
:chart_with_upwards_trend: Indicadores analisados

O dashboard apresenta diferentes perspectivas sobre o desempenho da operação, incluindo:

- Receita mensal
- Número de pedidos por mês
- Ticket médio
- Receita por categoria
- Pedidos por canal de venda
- Status dos pedidos recentes

Esses indicadores permitem uma análise tanto da evolução geral das vendas quanto da composição da receita e do comportamento dos pedidos.

:computer: Dashboard



:mag: Principais análises

A construção do dashboard buscou ir além da simples apresentação dos números, utilizando os dados para facilitar a identificação de:

- Tendências de crescimento ou redução das vendas;
- Variações no volume de pedidos;
- Categorias com maior contribuição para a receita;
- Diferenças de desempenho entre os canais de venda;
- Comportamento do ticket médio;
- Situação dos pedidos mais recentes.

A organização visual dos indicadores foi pensada para permitir uma leitura rápida dos resultados e, ao mesmo tempo, possibilitar uma análise mais detalhada por diferentes perspectivas.

:rocket: Possíveis aprimoramentos

O projeto pode ser expandido futuramente com novas análises e funcionalidades, como:

- Análise de sazonalidade;
- Crescimento percentual da receita e dos pedidos;
- Segmentação por perfil de cliente;
- Análise de recorrência e retenção de clientes;
- Indicadores de conversão;
- Análise de margem e rentabilidade;
- Inclusão de filtros e segmentações adicionais;
- Criação de indicadores e alertas para acompanhamento de resultados.

:hammer_and_wrench: Ferramentas

Power BI — tratamento, análise e visualização dos dados;
DAX — criação de medidas e indicadores;
Power Query — transformação e preparação dos dados.

:bulb: Aprendizados

Este projeto foi uma oportunidade para desenvolver não apenas conhecimentos técnicos relacionados à análise e visualização de dados, mas também a capacidade de transformar informações em insights de forma clara e objetiva.

Um dos principais aprendizados foi perceber que um bom dashboard não deve apenas apresentar dados: ele deve facilitar a interpretação das informações e ajudar o usuário a responder perguntas relevantes sobre o negócio.

Este projeto está em constante evolução e sugestões e críticas construtivas são muito bem-vindas.
